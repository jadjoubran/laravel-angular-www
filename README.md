# laravel-angular.io

Static archive of laravel-angular.io. There is no build step: `docs/` is exactly what GitHub Pages serves (Settings → Pages → Deploy from branch `master`, folder `/docs`).

- **Edit**: change the HTML in `docs/` directly. The "archived" course list is repeated in every page, so use find-and-replace across `docs/` (e.g. search for `Learn AI`).
- **Preview**: `npm start`, then open http://localhost:8080
- **Deploy**: push to `master`.
